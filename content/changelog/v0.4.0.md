### Canvas, elements, and layout `shipped`

- The canvas and element model — draw, select, move, resize, and nudge rectangles, text, images, and form inputs. [Canvas](/docs/canvas)
- CSS Grid containers with column and row tracks and per-item placement. [Grid Layout](/docs/grid-layout)
- Group and ungroup into flex containers. [Grouping](/docs/grouping)
- Change an element's HTML tag without breaking its CSS class. [Elements](/docs/elements)

### Components `shipped`

- Reusable components shared across pages, with a dedicated editor
- Per-instance text overrides, and detach an instance back into plain elements. [Components](/docs/components)

### Styling and theming `shipped`

- Color picker with alpha, hex entry, project swatches, and theme tokens. [Color Picker](/docs/color-picker)
- Color tokens and typography tokens backed by a real `theme.css`. [Design System](/docs/design-system)
- Hover, active, and focus styles via the State Switcher. [Element States](/docs/element-states)
- Transitions between states, and preset keyframe animations with full timing control. [Animations](/docs/animations)
- Per-breakpoint overrides, with the canvas switching to the breakpoint's width. [Breakpoints](/docs/breakpoints)

### Code, output, and the app itself `shipped`

- Bidirectional file sync — real TSX and CSS Module files written as you design, and external edits reflected back on the canvas. [Bidirectional Sync](/docs/bidirectional-sync)
- Export the page or a selected element as PNG or SVG. [Export](/docs/export)
- Preview mode running a real Next.js dev server. [Preview Mode](/docs/preview)
- Snapshots and the visual History panel. [Snapshots](/docs/snapshots)
- Crash reporting, automatic updates, and Windows/macOS packaging
