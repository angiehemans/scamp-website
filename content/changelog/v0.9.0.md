### The Scamp Agent, in beta `shipped`

- Click **Agent** in the sidebar, connect your own Claude API key, and describe a change in plain words. The agent reads your design, edits it through the same tools the properties panel uses, and saves the result to your files
- It works on the page you have open or across the whole project, and it can measure a page in a browser to find what overflows
- It asks before it deletes, creates components, changes theme tokens, or makes many changes at once, and **Undo AI changes** puts back everything it did in a conversation
- Each page keeps its own conversation, saved in the project, and new projects keep those conversations in version control so a team sharing a repository shares them
- The agent needs you to be signed in, and Anthropic bills its use to your key; the connect screen says what's sent to Anthropic. [Scamp Agent](/docs/scamp-agent)
- **Clean up an imported page with AI.** After you import a page, click **Clean up with AI** in the import window. The agent makes the page easier to edit—shorthand values instead of per-side ones, flex layout, theme tokens if you want them—without changing how it looks, and shows you a plan before it changes anything. [Clean up an imported page](/docs/scamp-agent#clean-up-an-imported-page)

### Import pages from a React app `shipped`

- Choose a React app's folder, and Scamp runs it, lists its routes, and imports the ones you pick into a new project, in one step you can undo
- The app's own components become Scamp components, its `.map()` lists become repeats, and the theme tokens it used come across where it used them
- **Tidy up with AI** then reads the app's source to name its lists and find what it shows only some of the time. [Import pages from a React app](/docs/website-import#import-pages-from-a-react-app)

### Tables `shipped`

- Change a container's tag to `table`, and draw rows and cells inside it. A table is laid out as a grid with its column widths set once, on the table, so the header and the body always line up
- Dividers, stripes, a sticky header, cell padding, and cell alignment are each set once in the new **Rows and cells** section
- A table on an imported page now arrives as a table, not as loose cells. [Tables](/docs/tables)

### A Checks section lists what's wrong with a view `shipped`

- Undeclared theme tokens, values the panel can't edit, loose text, and misplaced table parts appear at the top of the panel, grouped and worst first; click one to select the element
- Scamp used to find these only for agents, so a project could have thousands without anyone seeing them. [Find problems in a view](/docs/views#find-problems-in-a-view)

### More additions `shipped`

- **An icon's color controls come first.** With an SVG selected, the **SVG** section, with its colors and stroke width, sits above **Background** in the Visual panel. Icons that set their color on the `<svg>` tag, as Lucide and Tabler icons and agent-written icons do, now show their colors instead of "No editable colours", and **Current color** shows the color an icon inherits
- **The component editor has its own breakpoint.** Click the size control above a component's canvas and select a breakpoint to see and edit the component at that screen size, without resizing its canvas. The editor always opens at Desktop, and a page gets its own breakpoint back when you return. [Breakpoints](/docs/breakpoints#breakpoints-in-the-component-editor)
- **Outside agents get more from the MCP server.** `scamp_get_element_tree` and `scamp_get_element_by_id` read any view or component, not only the open one, and two new tools measure overflow and read a React import's source. Agents also learn tables from `agent.md`. [Work with AI agents](/docs/ai-agents)

### Fixes `shipped`

- **Double-clicking a component on the canvas opens its editor.** A layer over the canvas caught the double-click first. The breadcrumb and **Esc** now take you back to the page or view you came from
- **The component editor shows a component the way your pages do.** A component with tablet styles showed them at Desktop, text inside a nested `<span>` was dropped on pages, and a component set to `height: 100%` stopped short of the row it sat in
- **Leaving a component opened from the sidebar goes back to the view you were on.** In a project made of views, it showed an empty canvas
- **Esc closes the canvas size menu without leaving the component editor**
- **Emphasis and other inline tags stay where they are in a sentence.** `Hello <em>world</em> again` became `Hello again world` when Scamp saved. Inline tags now stay in place, with the spaces around them, on the canvas, in the files, and in the HTML export, which also now keeps styled words
- **Opening a project no longer moves a centered element.** An offset written as a percentage or a calculation, such as `left: 50%`, was read as `0`, so the next save wrote `left: 0px`. Scamp now keeps those values as written
- **Saving an agent-edited page no longer warns that it rewrote the whole stylesheet.** The check mistook two orderings of the same rule for different designs
- **Fit keeps a page readable when something overflows it by a lot.** Fit now shows overflow up to half the page's width, and you scroll for the rest
- **The breakpoint menu lines up with the right edge of the page** at every zoom, not with the edge of the canvas area
- **Edits at a breakpoint close their `@media` block on its own line**
- **Imported pages keep more of their layout.** Values set per side are combined into one shorthand where they match, gaps are written once, named grid areas and form-control sizes come across, and text the page hides no longer appears
