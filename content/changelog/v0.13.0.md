### The canvas draws your page the way a browser does `shipped`

- Scamp now draws the page from the same HTML and CSS it writes, in a document of its own, as the preview does. Breakpoint rules (`@media`) apply at the canvas width, `vh` and `vw` units measure the page, and your page's styles can't mix with Scamp's own, so what you design matches the preview more closely
- **A box that scrolls in your page scrolls on the canvas.** An element with `overflow: auto`, such as a table's container, now scrolls under the mouse wheel, and once it reaches the end, the canvas does. Hold **Shift** to scroll sideways. The canvas draws these scrollbars lighter, and doesn't save where you scrolled. [Canvas](/docs/canvas)
- **Note:** For this release you can switch back to the previous canvas: open the developer tools, and in the console enter `__scampIframeCanvas.set(false)`

### More room to work `shipped`

- **You can resize the left panel.** Drag its right edge to make the layers panel and the page and component lists wider, so long names aren't cut off. Double-click the edge to return to the default width. Scamp remembers the width for every project on this computer. [Layers panel](/docs/layers-panel)
- **You can hide the left panel.** Click the button of the open section in the sidebar, or press **Cmd+B**, to give the canvas more room. Click it or press **Cmd+B** again to show the panel at the same width. [Keyboard shortcuts](/docs/keyboard-shortcuts)
- **You can resize the code panel and the terminal.** Drag the top edge to make them taller or shorter. They share one height. [Code output](/docs/code-output)
- **A layer's tooltip shows its full name.** Hold the pointer over a layer to see its name above its CSS class. A page or component whose name is cut off shows its full name in a tooltip too

### Fixes `shipped`

- **A component instance you move stays where you put it.** Dragging an instance moved it on the canvas, but the page's files didn't record the move, so it went back when you reopened the page and in the preview. Scamp now writes the instance's `position`, `left`, and `top` to the page's CSS. An instance in a row, a column, or the page's flow doesn't change
- **The project's cover on the projects screen shows its home page.** If you saved the home page and opened another page within about a second, the other page could become the cover
- **The HTML export draws an instance in its variant.** An instance set to a variant, such as `variant="outline"`, exported in the component's default look
