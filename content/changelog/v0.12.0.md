### A tutorial teaches the basics by doing them `shipped`

- After you choose a projects folder for the first time, Scamp offers a tutorial project and a **Learn** checklist with five short lessons: drawing, layout, editing the code, components, and tokens. Each lesson is checked off when you do it
- You can skip it, hide the checklist, or start over from **Settings**. If you already use Scamp, you don't see it unless you start it from **Settings**. [Get started](/docs/getting-started)

### Changes `shipped`

- **A field's tooltip shows the token it applies and that token's value.** Hold the pointer over a field whose value is a theme token, and the tooltip adds a line such as `--space-md: 16px`. A token that points at another token shows the value at the end of the chain
- **Cmd-click adds to the selection, and Shift-click selects a range of layers.** Cmd-click (macOS) or Ctrl-click (Windows and Linux) adds an element to the selection or removes it, on the canvas and in the layers panel. In the layers panel, Shift-click selects every layer at the same level from the selected one to the one you click. On the canvas, Shift-click still adds or removes an element. [Layers panel](/docs/layers-panel)

### Fixes `shipped`

- **A component with a large variant set opens without freezing.** A component whose variant properties make more than 36 combinations used to draw every one of them. Scamp now draws only the frames the file defines, with a notice that the set is past the limit; select any other combination in the **Variants** section. Saving a large set is faster too, and **Checks** warns when a component is past the limit
- **A component inside another component draws on the page**, with its own styles, size, and variant picks, instead of a purple box with its name. To change its text, open the outer component
- **An agent's edit to a component shows on the canvas right away.** Scamp now re-reads a file an agent changes, whether or not it's open
- **A component with no background is transparent on the canvas**, as it is in the preview. A page or component whose file sets a white background keeps it, on the canvas and when Scamp saves the file
- **Note:** If a component that looked white on the canvas now looks see-through, its file doesn't set a background, and your app has always drawn it see-through. To make it white, select its root and set its background in the **Background** section
- **An element in normal flow stays in flow on the canvas.** A child of a block element with no `position` was drawn at the parent's top-left corner and saved as `position: absolute`. Scamp now reads it as `position: static`, and keeps `display: block` on a `<progress>` or `<meter>`
