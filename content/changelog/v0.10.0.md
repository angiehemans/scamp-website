### Edit several elements at once `shipped`

- With two or more elements selected, a change in the properties panel applies to every selected element it fits, as one undo step. Before, only the first selected element changed
- Typography reaches only text, and a component instance takes only a size
- A field the selected elements disagree on reads **Mixed**; type a value to set it on all of them. Shadows, Filters, Transform, and Transitions show **Mixed** when the lists differ, and adding a row replaces them all

### Group pages in the Pages list `shipped`

- Cmd+click (Ctrl+click) pages or Shift+click a run of them, then press **Cmd+G**, or right-click and select **Group**. Drag pages into a group, or right-click a page and select **Move to** a group
- Drag pages and groups into any order, and collapse a group to keep a big project scannable
- Groups change only the list: a page's files, route, and code are the same wherever it sits. The groups are saved in `scamp.config.json`, and collapsed groups are remembered on your computer
- **Add page and Import moved to the Pages header.** **Add page** is the **+** button beside the **Pages** title, and **Import** is the download button, with **Import from website…** and **Import from React app…** in its menu

### Agents `shipped`

- **Connect Codex, OpenCode, VS Code, and other agents to Scamp's MCP server.** The copy button on the terminal's **MCP** indicator now opens a menu of agents. Select yours to copy its connect command or config, with a note on where it goes
- **Agents can check the whole project in one call.** The new MCP tool `scamp_check_project` runs the **Checks** on every page, view, and component and lists what's wrong in each. `scamp_check_view` now checks plain pages too, and both read your files as they are now. [Work with AI agents](/docs/ai-agents)
- **Scamp keeps saving while an agent is open in its terminal.** Scamp used to pause saving whenever any program ran in the integrated terminal, including Claude Code sitting idle at its prompt. It now pauses only while files are actually changing, or when you click **Pause sync**. Each save still checks the file first and merges with whatever changed. [Bidirectional sync](/docs/bidirectional-sync)

### More additions `shipped`

- **See and update a project's scampjs version.** Project Settings has a **Framework** section that shows the installed `scampjs` version and, when npm has a newer release this version of Scamp supports, an **Update** button that installs it
- **Shadows that use a theme token show in the panel.** A `box-shadow: var(--shadow-card)` appears in the Shadow section by token name and keeps following the theme. **Detach** turns it into rows you can edit
- **Center with an auto margin.** The margin field takes `auto` on a side, so `0 auto` centers a fixed-width element
- **Set how an element sits among its neighbors.** A new **Display** choice in the Layout section—and a **Display** section for text and inputs—sets Block, Inline, Inline block, Contents, or List item, and makes a flex or grid container inline

### Fixes `shipped`

- **An exported element keeps its padding and type.** Exporting an element placed on the page, as a PNG or SVG, now draws it from the image's top-left at its own size
- **Exports embed the fonts they use**, Adobe Fonts and Google Fonts included, and no longer carry Scamp's own interface fonts. [Export](/docs/export)
- **Drop images onto the canvas again.** A PNG, JPEG, WebP, or GIF dragged from the file manager or a web browser is placed where you drop it. A drop Scamp can't use now says why
- **Click and drag a component instance on the canvas.** A click anywhere an instance draws now selects it, so you can drag it and double-click it
- **Dragging a side handle no longer resets the other dimension.** A side handle now changes only its own dimension, and a corner changes both
- **Shift-clicking on the canvas no longer selects the app's text**
- **Setting Block at a breakpoint no longer hides the element.** It wrote `display: none` instead of `display: block`
- **`tabIndex={-1}` is no longer reported as a broken binding**
- **Checks no longer report valid CSS as problems.** Values the panel has no control for are listed under **Edit in CSS** and left out of the count
- **Edits made while sync is paused are saved.** Resuming writes them, and switching to another page or component writes the one you leave
- **A save that fails no longer costs you the edit.** The next save writes it too, and **Retry** after a conflict merges instead of staying on **Saving…**
- **Closing or switching project stops the Scamp Agent**, so a reply in progress no longer keeps spending your key or edits the project you open next
- **A CSS panel edit and a canvas save no longer overwrite each other**
- **History survives a crash.** The snapshot list, `theme.css`, `DESIGN.md`, and your settings are written in one step. [Snapshots](/docs/snapshots)
- **Undo AI changes covers the agent's first edits**
- **Renaming or deleting a component keeps your recent edits** on the pages that use it
- **Agents connected over MCP get their requests intact**, including accented and other non-ASCII text
- **The Scamp Agent recovers when your key can't be read** and asks you to connect it again
- **Imported pages kept for the agent are private to your account** on a shared Linux machine
- **Leaving a page while you preview a snapshot keeps the live page**
